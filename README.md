# 💰 Expense Tracker

A full-stack Expense Tracker web application built as part of the Dalil Academy Full Stack Training.

The project allows users to add, view, edit, delete, and filter expenses through a responsive web interface connected to a PostgreSQL database.

---

## 🚀 Features

- Add new expenses
- View all expenses in a table
- Edit expenses using a Bootstrap Modal
- Delete expenses
- Filter expenses by category
- Summary cards:
  - Total Amount
  - Number of Expenses
  - Highest Expense
- Form validation
- Loading spinner
- Success and error messages
- Responsive design for mobile devices
- REST API using Express.js
- PostgreSQL database
